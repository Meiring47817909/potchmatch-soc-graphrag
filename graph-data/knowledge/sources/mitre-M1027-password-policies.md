# Password Policies (M1027)

Password Policies (M1027) is a Control. It sets rules for password strength, length, complexity, reuse and rotation so credentials are hard to guess and not recycled from breaches.

- Password Policies (M1027) mitigates Brute Force (T1110): long, unique passwords resist guessing, spraying and credential stuffing.
- Password Policies (M1027) mitigates Valid Accounts (T1078): fewer accounts are taken over through weak credentials.
- Password Policies (M1027) addresses the vulnerability Weak Passwords (VULN-WEAK-PASSWORDS).
- The password reset procedure (DOC-PASSWORD-RESET) implements Password Policies (M1027) by requiring a policy-compliant new password.
