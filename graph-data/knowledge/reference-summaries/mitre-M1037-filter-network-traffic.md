# Filter Network Traffic (M1037)

Filter Network Traffic (M1037) is a Control. It uses firewalls, gateways and proxies to allow, block or rate-limit traffic by source address, protocol or volume.

- Filter Network Traffic (M1037) mitigates Endpoint Denial of Service (T1499): abusive sources are blocked or throttled before they exhaust a service.
- Filter Network Traffic (M1037) addresses the vulnerability No Rate Limit (VULN-NO-RATE-LIMIT).
- Filter Network Traffic (M1037) also limits repeated login attempts from a hostile source, helping against Brute Force (T1110).
- The IP blocking procedure (DOC-IP-BLOCKING) implements Filter Network Traffic (M1037).
