# Account Use Policies (M1036)

Account Use Policies (M1036) is a Control. It configures how and when accounts may be used, such as lockout after a number of failed attempts, limits on login attempts over time, and restrictions on where or when an account can sign in.

- Account Use Policies (M1036) mitigates Brute Force (T1110): lockout and attempt limits cap the number of guesses.
- Account Use Policies (M1036) mitigates Valid Accounts (T1078): usage restrictions reduce what a misused account can do.
- Account Use Policies (M1036) addresses the vulnerability No Rate Limit (VULN-NO-RATE-LIMIT) for login attempts.
